# 0002. Cookie・アクセス解析・外部リソース読み込みを使用しない

- Status: Accepted
- Date: 2026-07-17

## Context

トクミルはカメラ・位置情報を扱うアプリであり、「Cookie・アクセス解析を使用しない」ことを公開サイト側でもプライバシー訴求の柱にしている(フッター表記、`README.md`)。Google Analytics等の解析タグや、Google Fonts等の外部CDNからのリソース読み込みは、それ自体がユーザーのIPアドレス等を外部サーバーへ送信する行為であり、この訴求と矛盾する。

2026-07にサイトのビジュアル強化(グラデーション・モーション演出・アイコン追加)を行った際も、この制約により「外部フォントCDNの利用」を明示的に却下し、システムフォント・自己完結アセット(インラインSVG、CSSのみのグラデーション、外部依存のないvanilla JS)で実現した実績がある。

## Decision

公開サイトでは以下を禁止する。

- Cookieを発行する仕組み
- アクセス解析ツール(Google Analytics等)の埋め込み
- Google Fonts等、外部ホストから読み込むフォント・スクリプト・スタイルシート・画像等のリソース

デザイン強化や機能追加が必要な場合も、システムフォント・自己完結アセット(リポジトリ内に同梱したファイルのみ)で実現する。JavaScriptを追加する場合も外部ライブラリ・CDNには依存しない。

## Consequences

- Webフォントによる表現の幅、外部解析による効果測定は行えない。
- SNS埋め込み(Xの埋め込みツイート等、外部スクリプトを読み込むもの)を追加する際は本ADRとの整合性を個別に検討する必要がある。
- この制約を変更したい場合は、フッターの「Cookieやアクセス解析を使用しません」表記の変更とセットで本ADRを見直す。
