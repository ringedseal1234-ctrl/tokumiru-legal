# 0003. マーケティングコンテンツは別のプライベートリポジトリで管理する

- Status: Accepted
- Date: 2026-07-18

## Context

本リポジトリはGitHub Pages上で公開されるJekyllサイト専用であり、[0001](0001-app-source-lives-in-a-separate-repository.md)により「公開してよい情報のみを置く」という境界がすでに定められている。

マーケティング活動(note記事、X投稿等)のコンテンツ作成・管理を進めるにあたり、下書き段階の文言には公開前は伏せておきたい社内情報が含まれうる。本リポジトリは公開リポジトリであり、一度コミットした内容はgit履歴に残り続けるため、非公開であるべき情報の置き場所として適さない。

## Decision

マーケティングコンテンツの作成・管理(下書き・関連する内部メモを含む)は、本リポジトリとは別のプライベートリポジトリ(想定名: `tokumiru-marketing`)で行う。本リポジトリには未公開のコンテンツ下書きや、その検討過程の内部メモを置かない。

本リポジトリの役割は [0001](0001-app-source-lives-in-a-separate-repository.md) のとおり「公開サイト(紹介・サポート・法務ページ)専用」のまま変更しない。`content/` のようなディレクトリを本リポジトリに新設しない。

## Consequences

- 公開サイトの文言(トップページのコピー等)とマーケティングコンテンツの訴求軸を揃える必要がある場合、その調整作業は `tokumiru-marketing` 側の資料を参照して行う。本リポジトリ側に同種の資料を複製・二重管理しない。
- 「公開済みのnote記事等を公開サイトにも一覧掲載したい」等の要望が将来出た場合は、本文を転載せず外部リンク一覧の形式に留めるか、改めて本ADRを見直す。
- `tokumiru-marketing` リポジトリ自体の運用ルールは当該リポジトリ側のAGENTS.mdで定義する。本リポジトリのAGENTS.mdには詳細を書かない。
